# Actividad 1 – NormSkincare | C++

## Project Overview
This project was developed as part of the subject **Fundamentos de Programación** at UNIR.

It consists of a practical programming activity based on the NormSkincare business scenario, using C++ to solve the proposed exercise.

## Project Objectives
- Understand the problem statement.
- Design the solution using pseudocode.
- Translate the solution into C++ code.
- Practice basic programming concepts and problem-solving skills.

## Project Files
- **Enunciado:** Original assignment instructions.
- **Explicación:** Explanation of the solution and pseudocode.
- **Código C++:** Source code developed for the activity.

## Tools & Technologies
