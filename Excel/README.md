# Online Orders Analysis – Excel

## Project Overview
This project focuses on analyzing online orders using Microsoft Excel.

It uses a simulated dataset to demonstrate how business order information can be organized, processed and analyzed.

## Objectives
- Organize online order data.
- Calculate quantities and net amounts.
- Analyze sales and expenses.
- Improve data accuracy using Excel formulas.
- Support business decision-making.

## Tools & Skills
- Microsoft Excel
- Data Cleaning
- Excel Formulas
- Data Analysis
- Business Reporting

## Dataset
The dataset contains fictional order information created for portfolio and learning purposes.

Practical Data Analysis Project
